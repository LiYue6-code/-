# 就业管理系统（Employment Management System）

软件工程综合实训课程项目（第 22 组）。面向 **学生** 与 **学校负责人** 两类角色的就业管理信息化平台，实现就业岗位发布、申请、自报、审核、录用及统计的全流程管理。

## ⚠️ 拉取本仓库后必做（3 分钟）

1. **先执行数据库增量脚本，再启动，否则启动报错**（代码已用到 `audit_log` 等新表新字段，`schema.sql` 中没有）：

   ```bash
   mysql -u root -p employment_db < sql/migration_v2.sql
   ```

   > MySQL 8.0 不支持 `ADD COLUMN IF NOT EXISTS`，该脚本**只能执行一次**。

2. **接受 GitHub 合作邀请**：组长邀请后需在通知/邮件里点 *Accept invitation*，否则 `pull` 正常但 `push` 会报 `403 denied to <你的账号>`。
   自查：`gh api repos/LiYue6-code/- --jq .permissions`（`push: true` 才能推）。

3. **改 `static/css/style.css` 前先 `git pull`**：该文件是多人共用冲突热点。审核/统计模块的样式**追加在文件末尾**（`/* ===== 审核与统计模块新增样式（张伟旗） ===== */` 起），冲突时**两边都保留**，不要整段覆盖。

> 分支、提交信息、数据库变更、公共文件、模块边界、常见报错等完整规则见 **[CONTRIBUTING.md](CONTRIBUTING.md)**。

## 功能

1. 学生、招聘单位及岗位信息维护；
2. 学校负责人发布岗位；
3. 学生查询并申请岗位；
4. 负责人根据反馈登记申请审核、面试及录用情况；
5. 学生自主上报就业信息及证明材料，负责人审核、退回补正或确认；
6. 学生查询处理进度；
7. 岗位、申请及就业去向查询统计。

## 技术栈

- Java 17 + Spring Boot 3.5
- MyBatis（数据访问）
- MySQL 8.0（数据库）
- Thymeleaf + HTML/CSS（前端）
- Maven（构建）、Lombok（简化实体代码）

## 快速开始

### 1. 准备环境

- JDK 17+（建议 17–21）
- Maven 3.8+
- MySQL 8.0

### 2. 初始化数据库

```bash
mysql -u root -p < sql/schema.sql
mysql -u root -p < sql/data.sql
mysql -u root -p employment_db < sql/migration_v2.sql
```

或在 MySQL 客户端中依次执行三个脚本。

> `migration_v2.sql` 是「申请审核 / 就业审核 / 查询统计」模块的增量脚本（审核日志表 `audit_log`、审核相关字段、证明材料原始文件名字段）。已建库的必须执行；MySQL 8.0 不支持 `ADD COLUMN IF NOT EXISTS`，该脚本只需执行一次。

> 若数据库已按旧版脚本建过，请改为执行 `sql/migration.sql`（为登录失败锁定新增字段）。历史明文密码会在应用首次启动时自动升级为 BCrypt 密文，无需手动处理。

### 3. 修改数据库连接

编辑 `src/main/resources/application.yml`，将 `username` / `password` 改为本机 MySQL 账号密码（默认均为 `root`）。

### 4. 启动

```bash
mvn spring-boot:run
```

访问 http://localhost:8080

## 说明

### 学生端模块（杨丰隆）

| 能力 | 说明 |
|---|---|
| 岗位查询 | 按关键字（岗位名称/招聘单位）与招聘单位筛选，每页 10 条分页；只展示「招聘中」的岗位 |
| 岗位申请 | 申请前依次校验岗位存在、仍在招聘、本人未重复申请；列表与详情页均标记「已申请」，岗位已截止时不再显示申请按钮 |
| 就业信息上报 | 单位/岗位/薪资长度校验对齐表结构，支持证明材料上传（≤5MB）；被退回后只显示补正表单，重报后回到「待审核」且重报次数 +1 |
| 处理进度查询 | `/my/progress` 汇总岗位申请与就业上报，含申请总数、待初审、初审通过、已录用四项统计与「待补正」提醒；单条记录可查看完整处理时间线 |

详细说明见 [docs/交付说明_学生端模块.md](docs/交付说明_学生端模块.md)。

### 审核与统计模块（张伟旗）

| 能力 | 说明 |
|---|---|
| 申请审核列表 | 按学生/学号/岗位/单位关键字、初审状态、申请日期区间筛选，分页；支持导出 CSV |
| 申请审核详情 | 初审（通过/不通过必填原因）→ 安排面试（时间、地点）→ 登记面试结果 → 登记录用，全部由状态机校验 |
| 审核日志与时间线 | 每次状态变更写入 `audit_log`，负责人端与学生端均可查看完整处理进度 |
| 就业信息审核 | 查看/下载证明材料（PDF/图片/Word，≤5MB）；确认通过或退回补正（退回必须填补正内容） |
| 退回补正闭环 | 学生可在原记录上修改并重新上报，状态回到「待审核」，重报次数 +1，不再产生重复记录 |
| 查询统计 | 概览 8 项指标 + 岗位申请量 Top10、单位申请量 Top10、专业分布、月度趋势、审核状态分布、就业去向分布；支持时间范围筛选与 CSV 导出 |
| 状态机 | `ApplicationFlow` / `EmploymentFlow`，纯逻辑、可单测；页面按钮由状态机结果驱动，非法操作直接拒绝 |

状态定义：

- 申请：`status` 待审核 → 通过 / 未通过；`interview_result` 未安排 → 待面试 → 面试通过 / 面试未通过；`hire_status` 待定 → 已录用 / 未录用
- 就业：`status` 待审核 → 已确认 / 已退回 → （学生重报）待审核

运行测试：

```bash
mvn test
```

### 其他

- 上传的证明材料默认保存在运行目录下的 `uploads/` 文件夹，文件名使用 UUID 重命名并限制扩展名，避免路径穿越与重名覆盖。
- 密码使用 BCrypt 加密存储；连续登录失败 5 次锁定 15 分钟；所有写操作均有 CSRF 防护；退出登录需 POST。
- 学生信息维护：负责人端「学生管理」支持新增/编辑/删除/重置密码/禁用启用；学生端「个人中心」支持修改本人资料与密码。
- 该项目为课程实训的初步版本，后续可按功能模块继续扩展（如岗位编辑、简历管理、图表统计、导出报表等）。
